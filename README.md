# 전세사기 조기경보 서비스

계약서와 등기부를 분석해 임대차 계약의 위험 신호를 찾고, 판단 근거와 확인할 항목을 보여주는 팀 프로젝트입니다. 현재는 기획 및 초기 개발 자료를 정리하는 단계입니다.

## 서비스 흐름

문서 업로드 → OCR·마스킹 및 추출 결과 확인 → RAG 근거 검색·위험 분석 → 리포트·특약 수정안 → 일정 및 등기 변동 안내

첫 프로토타입은 업로드부터 OCR과 근거 검색까지를 목표로 합니다. 등기 정보 자동 조회 방식은 API 이용 가능 여부에 따라 정합니다. 재확인 알림 후 재업로드한 등기부를 비교하는 방식도 검토합니다.

## 개발 및 협업

- FastAPI, React, PostgreSQL·pgvector, PaddleOCR 등은 제안서의 후보입니다. 실행 방법과 의존성은 팀이 기술 스택을 확정한 뒤 추가합니다.
- 작업 범위를 Issue에 적고, 별도 브랜치에서 변경해 PR로 검토합니다. 브랜치·커밋·PR 작성 예시는 [팀 컨벤션](CONTRIBUTING.md)을 참고하세요.
- [분석 결과 형식 초안](docs/analysis-result.md)은 모듈 연동 논의에 사용합니다.
- 로컬 환경변수는 `.env.example`을 참고해 `.env`에 설정합니다. 공개 저장소에는 실제 계약서·등기부, 개인정보, 비밀 키를 올리지 않습니다. 원본 문서는 저장소 밖에 두고 테스트에는 가상 자료를 사용합니다.
