# 지식베이스 출처

법령, 판례, 공개 피해 예방 자료, 표준계약서 양식의 출처를 정리합니다. 자료별 원본 링크, 기준일 또는 버전, 이용 조건을 기록합니다.

## 출처 목록

| 자료 | 폴더 | 출처 | 기준일 | 이용 조건 |
| --- | --- | --- | --- | --- |
| 법령 조문 | [laws/](laws/) | 국가법령정보 공동활용 Open API (open.law.go.kr) | 각 법령 시행일, [manifest.json](laws/manifest.json) 참고 | 법령은 저작권법 제7조에 따라 보호받지 않는 저작물 |
| 백문백답 | [qna/](qna/) | 법제처 찾기쉬운 생활법령정보 백문백답 (공공데이터포털 법제처 API) | 질문별 `service_date`, 수집 시각은 [manifest.json](qna/manifest.json) | 공공데이터포털 이용허락범위 제한 없음 |

## 법령 (laws/)

| 법령 | 범위 | 쓰는 곳 |
| --- | --- | --- |
| 주택임대차보호법 | 전체 | 대항력, 우선변제, 임대차기간, 계약갱신, 임대인 정보 제시 의무 |
| 주택임대차보호법 시행령 | 전체 | 최우선변제 소액임차인 범위와 금액 |
| 민법 | 제303-319조(전세권), 제618-654조(임대차) | 전세권·임대차 일반 규정 |
| 전세사기피해자 지원 및 주거안정에 관한 특별법 | 전체 | 피해자 요건과 지원 절차 |
| 공인중개사법 | 전체 | 중개대상물 확인·설명 의무 |

법령 하나당 JSONL 파일 하나이고, 한 줄이 조문 하나입니다. 항·호·목은 `text` 안에 줄바꿈으로 이어져 있습니다. 삭제되었거나 다른 조로 옮겨진 조문은 뺍니다.

```json
{
  "id": "law:001248:제3조의2",
  "source_type": "law",
  "law_id": "001248",
  "law_name": "주택임대차보호법",
  "law_type": "법률",
  "chapter": null,
  "article": "제3조의2",
  "article_title": "보증금의 회수",
  "text": "제3조의2(보증금의 회수)\n① 임차인(...)이 ...",
  "effective_date": "2026-01-02",
  "promulgation_date": "2025-10-01",
  "promulgation_no": "21065",
  "url": "https://www.law.go.kr/법령/주택임대차보호법/제3조의2",
  "collected_at": "2026-11-27T14:40:00+09:00"
}
```

- `id`는 조문마다 고유하고, 다시 수집해도 바뀌지 않습니다. 임베딩을 갱신할 때 키로 씁니다.
- `chapter`는 편·장·절 제목입니다. 장 구분이 없는 법령은 `null`입니다.
- `url`은 국가법령정보센터의 조문 공개 주소입니다. 리포트에서 근거 링크로 씁니다.

### 다시 수집하기

법령이 개정되면 `backend` 폴더에서 수집을 다시 돌리고 바뀐 파일을 커밋합니다. `.env`에 `LAW_API_OC`가 있어야 합니다.

```bash
python -m app.collectors.laws          # 전체
python -m app.collectors.laws 민법      # 이름에 '민법'이 들어간 법령만
```

법령을 추가하거나 범위를 바꾸려면 [law_targets.py](../../backend/app/collectors/law_targets.py)를 고칩니다.

## 백문백답 (qna/)

법제처 찾기쉬운 생활법령정보(easylaw.go.kr)의 질문·답변입니다. 법령 조문보다 쉬운 말로 되어 있어서, 사용자 질문과 맞는 근거를 찾고 리포트 설명을 쓸 때 씁니다. 파일은 `easylaw_qna.jsonl` 하나이고 한 줄이 질문 하나입니다.

### 어떻게 모으나

공공데이터포털 법제처 API 3개를 씁니다. `.env`에 `PUBLIC_DATA_API_KEY`가 있어야 합니다.

| 단계 | API | 하는 일 |
| --- | --- | --- |
| 1 | 분류별백문백답 목록 조회 (조건 조회) | 대분류 "부동산/임대차"의 질문 목록에서 주택임대차, 전세사기 피해자 지원, 부동산등기, 부동산 경매, 공인중개사 1·2 중분류만 남김 |
| 2 | 분류별백문백답 목록 조회 (검색어 조회) | "전세", "보증금"으로 다른 분류의 질문을 찾음. 질문에 전세·주택임대차·임차주택·확정일자·전입신고가 있을 때만, 상가임대차는 뺌 |
| 3 | 백문백답법령명검색 목록 조회 | 주택임대차보호법, 전세사기피해자법과 연결된 질문을 찾음 |
| 4 | 백문백답항목 조회 | 질문마다 답변 전문, 관련 법령, 관련 생활법령 해설 링크를 받음 |

대상 분류와 검색어는 [qna.py](../../backend/app/collectors/qna.py) 위쪽 상수에서 바꿉니다. 개발계정은 API마다 하루 1,000건이라, 한 번 돌리면 항목 조회를 100건쯤 씁니다.

```bash
python -m app.collectors.qna      # backend 폴더에서
```

### 형식

```json
{
  "id": "qna:2472",
  "source_type": "qna",
  "question": "임대인과 임차인 모두 계약갱신에 대한 별다른 말이 없는 경우 계약은 어떻게 되나요?",
  "answer": "임대인과 임차인 모두 특별히 별도의 말이나 행동이 없는 경우 임대차계약은 갱신된 것으로 봅니다.\n◇ 묵시적 갱신의 요건\n...",
  "category": "부동산/임대차",
  "subcategory": "주택임대차",
  "subject": "재계약",
  "related_laws": ["주택임대차보호법 제6조, 제6조의2, 제6조의3 및 부칙<제17470호> 제2조", "주택임대차보호법 제4조"],
  "related_guides": [{"title": "주택임대차 > 임대차계약 갱신 > 임대차계약의 갱신", "url": "https://www.easylaw.go.kr/..."}],
  "url": "https://www.easylaw.go.kr/CSP/csp1/lifeLawDetail/getOnhunqueDetail.do?onhunqnaAstSeq=84&onhunqueSeq=2472",
  "service_date": "2021-01-05",
  "found_by": ["분류:주택임대차", "법령:주택임대차보호법"],
  "collected_at": "2026-11-27T15:10:00+09:00"
}
```

- `answer`는 HTML 태그를 지우고 문단마다 줄을 바꾼 텍스트입니다.
- `related_laws`는 백문백답이 근거로 단 법령 조문입니다. [laws/](laws/)의 조문과 이어 붙일 때 씁니다.
- `found_by`는 어느 조건으로 찾았는지입니다. 검색어로만 찾은 질문(`검색어:`만 있음)은 관련도가 낮을 수 있습니다.
