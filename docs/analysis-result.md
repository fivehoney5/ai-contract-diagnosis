# 분석 결과 형식 초안

업로드를 처리하는 서비스 서버와 분석 엔진이 주고받을 형식을 논의하기 위한 문서입니다. 예시는 가상 데이터이며 필드명, 필수 여부, 오류 응답, 개인정보를 저장하는 범위는 팀에서 합의합니다.

~~~json
{
  "analysis_id": "sample-001",
  "risk_score": 78,
  "risk_level": "위험",
  "risk_items": [
    {
      "type": "가격 위험",
      "reason": "가상 시나리오의 가격 지표가 높습니다.",
      "evidence": []
    }
  ],
  "clause_suggestions": []
}
~~~

문서 분석 엔진이 점수와 지표를 만들고, AI 모듈이 근거와 설명을 제공합니다. 서비스 서버는 결과 조회 API를 제공하고 프론트엔드는 합의한 형식에 맞춰 표시합니다.
