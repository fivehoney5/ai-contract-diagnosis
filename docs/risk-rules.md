# 리스크 규칙표 초안

국토교통부 "안심 전세계약 체크리스트"의 항목을 규칙 기반 판정(`flags`)으로 옮긴 표입니다. 문서 분석 엔진(document/)이 계산하는 신호와, 자동으로 확인할 수 없어 사용자에게 안내만 하는 항목을 함께 정리합니다. 결과 형식은 [분석 결과 형식 초안](analysis-result.md)을 따릅니다.

> **초안 표시**: `[초안]`이 붙은 기준값과 등급은 팀 합의 전 값입니다. 회의에서 확정하기 전까지 코드에 상수로 박지 않고 설정값으로 둡니다.

## 읽는 법

- **단계**: 체크리스트의 전세 과정을 전·중·후로 묶었습니다. 전 = 계약 전, 중 = 계약 시, 후 = 계약 체결 후·잔금 지급 전/시/후.
- **자동 확인**: `가능`은 데이터만 있으면 엔진이 판정, `부분`은 일부만 판정하고 나머지는 안내, `불가`는 안내만 합니다.
- **데이터 출처**: `실거래가 API`, `건축물대장 API`, `등기부 PDF`, `계약서 특약 구역`, `계약서 본문`, `사용자 입력`, `없음`. `계약서 본문`(임대인란·보증금·주소)은 기존 목록에 없던 출처라 추가 표시합니다.
- **level**: 규칙에 걸렸을 때 내보내는 값입니다. 걸리지 않으면 신호를 내보내지 않습니다. `확인필요`는 등급에 반영하지 않습니다(분석 결과 형식 초안과 같음).
- **code 표시**: 기존 = `docs/examples/`에 이미 쓰인 코드, 신규 = 이 문서에서 새로 제안하는 코드.
- 비율은 0~1, 금액은 원 단위입니다. `threshold`에는 판정에 쓴 경계값 하나를 넣습니다(구간이면 그 level의 하한).

## 팀 합의가 필요한 것

1. 선순위 부담률 구간: 저장소 예시(0.7 / 0.8)와 기준표 초안(0.6 / 0.7) 중 무엇으로 갈지.
2. 위험 경계를 "이상"으로 할지 "초과"로 할지 (전세가율·선순위 부담률 통일).
3. `[초안]` 표시한 level: 신탁등기 위험 여부, 비주거 용도 위험 여부, 건축물대장 없음·표준계약서 미사용·불리한 특약의 주의 여부.
4. 등기부 발급일 허용 기간(7일 초안), 신축 판단 기간(1년 초안).
5. 계약 후·잔금 단계 항목을 신호(`flags`)로 낼지, 별도 안내 목록으로 뺄지.
6. 안내서에는 전세가율·선순위 부담률의 70%·80% 같은 수치 기준이 없습니다(p.15~25 확인). 80%는 HUG 등기부 웹페이지, 70%는 팀 초안에서 온 값이라는 점을 회의에서 공유하고 출처 문구를 정할지.
